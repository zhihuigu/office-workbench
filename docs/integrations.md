# 核心与可选接入

| 能力 | 本仓库包含 | 需要用户另行准备 | 本候选验证 |
|---|---|---|---|
| CASE、看板、版本、历史检索 | Python 核心与模板 | Python | 本地隔离测试 |
| 自然语言交代工作 | 项目 AGENTS.md 和手册 | 已安装并登录的 Codex | 按快速开始自行做会话自检 |
| Word/Excel/PDF/PPT 制作与读取 | 文件存放与版本约定 | 适当文件工具、独立授权及依赖 | 未做连接器/Office 验证 |
| 邮件查询、附件 | 只读证据记录约定 | 用户自己的邮箱工具与授权 | 未验证 |
| 钉钉消息、听记、文档 | 来源与上下文边界说明 | 用户自己的 DWS 或其他正式接入 | 未验证 |
| 检索子 Agent | 不包含固定模型配置 | 需要时由用户自行选择能力 | 不属于本候选承诺 |

## 最小可用配置

Python + Codex + 新私人目录即可管理事项。它不自动安装 Skill、不创建 MCP 服务器、不调用 OpenAI API SDK，不要求 API key。现有 Codex 产品登录不能推出你同时拥有任何其他服务的授权。

## 连接器接入原则

1. 选择你信任、与你实际软件匹配的工具，从其官方文档了解安装、更新和许可证。
2. 按需授权最小范围，不把账户、端口、私有路径、token 或配置文件放进公开代码。
3. 在私人 LOCAL.md 记录工具名、适用场景和只读边界；凭据仍按该工具自己的安全机制管理。
4. 用你明确允许的少量资料做只读验证，确认定位和附件确实一致。
5. 明确区分原文、AI 摘要和推断。邮件记录日期、发件人、主题、文件夹/消息定位和附件；会议以原始转写为依据，AI 摘要只辅助。

本仓库不提供“某个工具名永远可用”的承诺，也没有连接器一键安装脚本。遇到不存在的工具，Codex 应说明限制，不能绕到未经授权的数据源或索要整份私人配置。

## 不要误判的边界

把附件保存进 sources 不代表本工具可以解读所有格式。JSON 搜索只找 CASE 记录，未实现全文 Office 搜索、语音转写、RAG 或云端同步。使用者自行增加的工具和 Skill 不自动适用本仓库许可证；必须各自核查。
